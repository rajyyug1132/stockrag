# Security policy

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/rajyyug1132/stockrag/security/advisories/new)
instead of opening a public issue. Include steps to reproduce and the affected
endpoint or file. Expect an initial response within a week.

API keys and tokens (`NVIDIA_API_KEY`, `SUPABASE_SERVICE_KEY`, `INGEST_TOKEN`) belong
in environment variables or host secrets, never in the repository.
